How a decision is made

Three independent checks look at every image. If any one of them fires, the image is marked sensitive, and the result lists which check fired and why.

Read the text

OCR finds every word and its position in the image.

Tesseract (browser) · PaddleOCR (server)

Check for IDs

Patterns are matched, then validated with the real checksum or numbering rules.

regex + Luhn, Verhoeff

Score the context

A trained text model spots passwords, medical details and confidential notes with no ID number.

TF-IDF + logistic regression

Score the picture

A fine-tuned CNN rates the whole image, which helps when the text is unreadable.

MobileNetV2

Decide and redact

Any check firing marks the image. Found IDs get solid black boxes, not blur.
